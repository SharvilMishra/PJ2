# Zuno Wellness Frontend

Responsive React and Vite interface for the PJ2 wellness dashboard. The current interface uses illustrative sample values based on the PJ2 data dictionary; connect the daily dataset and API when they are available.

## Run locally

```powershell
cd Frontend
npm install
npm run dev
```

The app includes a sign-in entry screen, overview dashboard, trends, appearance and notification preferences, and an editable profile. Sign-in and profile/preferences are frontend prototype interactions; they do not authenticate or persist data yet.
