# Project brief

## Purpose

Build a clear, responsive wellness dashboard for reviewing daily activity, sleep, recovery, stress, hydration, weight, and mood trends.

## Dataset subject

Emily Park is an invented 35-year-old highly active person with inconsistent sleep. The supplied data dictionary describes one record per day for 2025.

## Initial scope

- Summarize daily activity and wellness metrics.
- Explore trends over time and relationships between sleep, recovery, stress, activity, hydration, weight, and mood.
- Make units and metric definitions visible in the interface.
- Treat observations as descriptive, not as medical advice or diagnosis.
