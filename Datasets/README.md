# Datasets

`wellness_daily.csv` is a deterministic, synthetic demonstration dataset for the fictional profile Emily Park. It contains one generated record for each date in 2025 and follows the fields in `PJ2_data_dictionary.txt`. It is not measured or supplied source data and must not be interpreted as real health information.

The synthetic data supports local dashboard and API development while the real dataset is unavailable. Do not present it as Emily's observed health history. Keep any future supplied original data separate and unchanged.
